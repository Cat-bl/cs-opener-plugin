CS:GO 模拟开箱 · 帮助
# 可省略 · 命令与参数之间空格也可省
例：#cs 开箱 = cs开箱 = 开箱 (无)

金币 / 资产

#cs 签到每日领 500 金币（开箱主要收入。每日 0 点重置）
#cs 仓库看自己库存（含余额）
#cs 出售 [uid前4位+]出售单件（仓库图每个物品下方有 6 位 uid）
#cs 出售 全部一键卖光所有库存
#cs 出售 全部 [品质]只卖该品质：白/浅蓝/蓝/紫/粉/红/金

商城 / 开箱

#cs 商城默认显示武器箱列表
#cs 商城 [类别]类别可选：武器箱 / 纪念包 / 高光纪念包 / 印花胶囊 / 签名胶囊 / 布章包 / 胸章胶囊 / 涂鸦箱 / 音乐盒集
#cs 看 [箱名]查看箱子详情（含全部物品 + 概率）
#cs 开箱开你的默认箱（视频）。从未设置过 = 第一个武器箱
#cs 开箱 [箱名]直接开指定箱子，同时记忆为默认
#cs 选箱 [箱名]只切换默认箱不开箱（不花钱）。不带名 = 查看当前默认

筛选 / 重置

#cs 仓库 [品质]按品质筛选库存：白 / 浅蓝 / 蓝 / 紫 / 粉 / 红 / 金 / 暗金
#cs 重置存档清空自己的金币/库存/记录（需连发 2 次确认）

记录 / 统计

#cs 记录开箱历史 + 品质分布柱状图 + 最稀有掉落

概率

#cs 概率查看当前全局掉率（所有人统一，主人可改）

主人专属

#cs 更新数据增量下载箱图/物品图（首次必跑，约 5–60 分钟）
#cs 更新数据 强制重拉 crates.json 再下载（新箱出现时用）
#cs 状态查看下载任务实时进度
#cs 更新从 git 仓库拉最新插件代码
#cs 概率预设 [名]切全局预设：默认 / 欧皇 / 极品 / 均匀 / 残酷
#cs 设置概率 [档] [万分比]改全局单档：蓝 / 紫 / 粉 / 红 / 金
